# Password Strength Checker

Herramienta desarrollada en Python que evalúa la fortaleza de una contraseña en función de su longitud y genera un reporte local con fecha y hora de la evaluación.

## 🛠️ Características
- Validación de longitud de la contraseña.
- Clasificación de seguridad en pantalla.
- Generación automática de archivo de reporte con marca de tiempo (*timestamp*).

## 🚀 Requisitos e Instalación
- Python 3.x instalado.

No requiere librerías externas.

## 💻 Uso
Ejecutar el script desde la terminal:

```bash
python password.py
